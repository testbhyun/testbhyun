# 회의록 정리 도우미

## 언제 사용하나
- 사용자가 회의 메모, 녹취 텍스트, 대화 기록을 주고 정리를 요청할 때
- 회의 후 공유할 요약본이나 액션 아이템 목록이 필요할 때

## 작업 절차
1. 입력된 내용에서 회의 제목, 일시, 참석자를 확인한다. 없으면 "미기재"로 표시한다.
2. 논의 내용을 주제별로 3~5줄로 요약한다.
3. 확정된 결정 사항을 별도로 추출한다.
4. 할 일을 `담당자 / 내용 / 마감일` 형식으로 정리한다.
5. 불명확한 항목은 추측하지 말고 "확인 필요"로 표시한다.

## 출력 형식
```
# 회의록: {제목}
- 일시:
- 참석자:

## 요약
## 결정 사항
## 할 일
| 담당자 | 내용 | 마감일 |
|---|---|---|
```

## 주의 사항
- 원문에 없는 사실을 만들어내지 않는다.
- 간결한 문장으로 작성하고, 사용자의 언어를 따른다.
